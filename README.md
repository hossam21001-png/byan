## 🌟 نظرة عامة

**بيان** هي لغة برمجة عربية كاملة، تهدف إلى تمكين المبرمجين العرب من كتابة الكود بلغتهم الأم.

    انا_برنامج اسمي: "مرحبا بالعالم"
    الكود:
        اعرض("أهلاً بك في لغة بيان!")

---

## ✨ المميزات

### 🎯 لغة برمجة كاملة
- متغيرات، شروط، حلقات، دوال
- OOP كامل (فئات، وراثة، واجهات)
- قواميس وقوائم كاملة
- معالجة أخطاء (حاول/التقط/أخيرًا)
- ميزات متقدمة: استنتاج الأنواع، انعكاس، إدارة ذاكرة

### 🎨 دعم واجهات المستخدم
- عناصر UI جاهزة (أزرار، نوافذ، مدخلات، جداول، خرائط، 3D)
- توليد HTML/CSS/JS تلقائيًا
- PWA (تطبيق ويب تقدمي)

### 🌍 متعدد المنصات
- A: HTML مستقل (ملف واحد، يعمل في أي متصفح)
- B: Python Bundle (يعمل على أي نظام فيه Python)
- C: pyz (zipapp — ملف واحد قابل للتنفيذ)

### 📚 مكتبة قياسية غنية (12 وحدة)
- رياضيات، نصوص، قوائم، قواميس
- ملفات، شبكة، وقت، عشوائي
- JSON، CSV، تشفير، نظام

## 🎓 مثال سريع

### 1. اكتب ملف Byan

    انا_برنامج اسمي: "آلة حاسبة"
    الكود:
        دالة جمع(أ, ب):
            ارجع أ + ب

        انشئ زر:
            المعرف: "calc"
            النص: "احسب 5 + 3"
            عند_الضغط:
                متغير ن = جمع(5, 3)
                اعرض_في "النتيجة: {ن}" في: "#out"

        انشئ نصا:
            المعرف: "out"
            النص: ""

### 2. شغّله أو ابنيه

    python cli.py نفّذ file.byan
    python cli.py ولّد file.byan
    python cli.py ابنِ file.byan --وضع=الكل

### 3. المخرجات

    output/
    ├── file.html        ← A: HTML مستقل
    ├── file_py/         ← B: Python Bundle
    │   ├── program.py
    │   ├── byan_rt.py
    │   ├── run.sh
    │   └── run.bat
    └── file.pyz         ← C: zipapp

## 🛠️ الأوامر

### أوامر عربية

| الأمر | الوصف |
|-------|-------|
| python cli.py نفّذ ملف | تنفيذ مباشر |
| python cli.py ولّد ملف | توليد HTML/CSS/JS |
| python cli.py ابنِ ملف | بناء (A+B+C) |
| python cli.py شغّل ملف | توليد + تشغيل |
| python cli.py اختبر مجلد | تشغيل الاختبارات |
| python cli.py مكتبة | عرض المكتبة القياسية |
| python cli.py استورد حزمة | تنصيب حزمة |
| python cli.py تفاعل | REPL تفاعلي |

### أنماط البناء

    python cli.py ابنِ file.byan --وضع=ويب       # A فقط
    python cli.py ابنِ file.byan --وضع=python    # B فقط
    python cli.py ابنِ file.byan --وضع=pyz       # C فقط
    python cli.py ابنِ file.byan --وضع=الكل      # A+B+C (الافتراضي)

## 📖 اللغة

### المتغيرات

    متغير اسم = "أحمد"
    ثابت باي = 3.14
    محلي مؤقت = 5
    عالمي عداد = 0
    متغير س: عدد = 5

### الشروط والحلقات

    إذا عمر > 18:
        اعرض("بالغ")
    وإلا:
        اعرض("قاصر")

    لكل رقم في [1, 2, 3]:
        اعرض(رقم)

    طالما عداد < 10:
        عداد = عداد + 1

### الدوال

    دالة جمع(أ, ب):
        ارجع أ + ب

    اعرض(جمع(3, 4))   # 7

### OOP

    فئة شخص:
        متغير اسم = ""
        دالة هيئ(ا):
            هذا.اسم = ا
        دالة عرّف():
            ارجع "أنا " + هذا.اسم

    فئة مدير يمتد شخص:
        متغير قسم = ""
        دالة هيئ(ا, ق):
            أساس(ا)
            هذا.قسم = ق

    متغير أحمد = جديد مدير("أحمد", "IT")
    اعرض(أحمد.عرّف())

### القواميس

    متغير شخص = {الاسم: "أحمد", العمر: 25}
    شخص["المدينة"] = "القاهرة"

    لكل مفتاح, قيمة في شخص:
        اعرض(مفتاح, "=", قيمة)

### معالجة الأخطاء

    حاول:
        ارمِ_خطأ("مشكلة")
    التقط:
        اعرض("حدث خطأ:", خطأ)
    أخيرًا:
        اعرض("انتهى")

### الاستيراد

    استورد رياضيات
    استورد نصوص
    استورد JSON

    اعرض(رياضيات.جذر(16))
    اعرض(نصوص.كبير("abc"))
